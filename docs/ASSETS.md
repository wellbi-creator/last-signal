# Графика и лицензии

## Правила

1. Только собственные работы или ресурсы с разрешающей лицензией (CC0 или аналогичная). Ресурсы с неясной лицензией не используются.
2. Каждый внешний ресурс заносится в реестр ниже **до** добавления в проект: название, автор, ссылка, лицензия, где используется.
3. Формат: PNG без сглаживания, тайлы и спрайты 32×32 (кратные размеры для крупных объектов), атласы для групп спрайтов.
4. Палитра: приглушённая, «выцветшая», холодные тени, тёплые акценты света. Единая палитра для всех ресурсов; сторонние ресурсы при необходимости перекрашиваются под неё.
5. Свои ресурсы рисуются бесплатными инструментами: Piskel, LibreSprite, Pixelorama; карты и штампы зданий: Tiled.

## Возможные источники (CC0)

Kenney (kenney.nl), OpenGameArt (только с отметкой CC0), itch.io (только с лицензией CC0 на странице). Перед использованием лицензия перепроверяется на странице ресурса.

## Реестр

| Файл                 | Название     | Автор                     | Ссылка | Лицензия           | Где используется |
| -------------------- | ------------ | ------------------------- | ------ | ------------------ | ---------------- |
| `public/favicon.svg` | Иконка сайта | Проект «Последний сигнал» | —      | Собственная работа | Вкладка браузера |

Других ресурсов в M0 нет: экран каркаса состоит только из текста.
